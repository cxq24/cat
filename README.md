# 猫咖接待

竖屏猫咖接待小游戏，按用户提供的《开发文档2.md》和《UI参考2.md》实现。支持接待分配、当天占用、评分与事件、升级、本机存档，以及按平台权限启用的云存档、排行榜和分享。

[下载小红书上传测试 ZIP 包 v0.1.1](releases/cat-cafe-v0.1.1.zip)。下载 ZIP 后可上传平台测试，无需解压。此包已通过本地构建和测试，真机验证仍待完成。

v0.1.1 适配状态栏、安全区与平台胶囊，使用启动窗口快照和 `getWindowInfo` 实测数据避让，并在窗口变化后更新。新增模拟原生遮挡的浏览器回归验证。

[玩法升级方案](docs/玩法升级方案.md)说明营业主题、座位装备、独特猫咪机制和相遇图鉴的后续设计。

## 开发与测试

需要 Node.js 22+。在本仓库目录执行以下命令。

```sh
npm ci --cache /tmp/cat-cafe-npm
npm run dev
```

开发服务器使用 4173 端口，启动时构建浏览器试玩版。更改源码后重启服务器以重新构建。试玩版使用独立的浏览器模拟桥接，正式构建不包含该文件。

拿到 `cat-cafe-browser-preview.zip` 后，解压并在该目录运行 `python3 -m http.server 4173`，再通过浏览器访问该静态服务。已验证 HTTP 试玩流程。本云环境禁止浏览器直接访问 `file://`，因此没有验证双击 HTML 文件启动。

```sh
npm test
npm run build
npm run test:ui
npm run package
```

浏览器测试使用系统 Chromium，路径可在 `playwright.config.js` 中调整。正式产物位于 `dist/`，脚本为外置经典脚本，目标为 ES2017 / Chrome 61。素材全部在包内，无运行时外部请求。

## 游戏规则与补充决定

- 购买从下一天生效。当日中断后重开，未打烊的收入不入账。打烊收入按营业天数去重。
- 评分 v2 的诉求分为完全合拍 30、基本合拍 20、未满足 0。界面展示每项具体原因。无硬限制时限制项得 40 分。未指定座位时座位项得 15 分。拍照不因毛长或睡觉额外扣分，亲子需求不因抢镜扣分。旧结算和金币继续使用当时的记录。
- 两只猫中任意一只当天记有对方为争吵对象，即构成争吵关系。相邻安排时第二桌扣气氛分，第一桌补事件，已发收入保留。
- 最新会话中的排行榜和分享要求优先于早期文档的非目标。榜单指标采用单日平均接待分（0–100），先提供周榜和总榜。
- 云存档合并按天去重收入，解锁按唯一项目合并，再按可用金币核算。若多端重复打完同一天，以较晚完成的一份记录为准。同一时间的冲突使用稳定顺序。数据读取失败保留原存档，不初始化覆盖。
- 云同步在启动与营业间歇执行，每分钟最多自动发起一次。云端写入 UNKNOWN 或网络结果未知时，保留待确认信息，只查询核对，不盲目重发。存档过大时保留本机数据并提示云同步不可用。

## 小红书接入

本机 Storage 需要客户端 9.46.0+。云存储和排行榜需要 9.51+ 与相应内测权限，提交排行榜时上传配置还需勾选“用户头像昵称授权”。分享需要 9.53+ 与全屏容器。版本、方法和接口失败均需分别处理。正式产物无浏览器存储回退。

开发文档公开页没有给出云存储和排行榜的收费标准。当前能力接入使用文档中的接口，真实权限、计费、跨设备与 Android/iOS 行为仍须在平台验证。

上传前需从小工具上传页取得当前完整开发／改写口令，并执行其中指定的官方 Skill 校验和打包。仓库的本地构建和测试不能代替该步骤。

## 视觉与素材

暖纸色、墨绿与焦糖色。猫和客人采用本项目绘制的 CSS 原创角色，首页场景为 AI 辅助生成的原创插画。界面说明页包含相应标识。参考网站仅用于结构、交互原则与信息层级。Game UI Database 返回 403，未读取其图库。

短屏安排台把多只猫放在可横向滑动的选择栏，与座位和需求同屏；常规尺寸保留猫咪网格。浏览器读取 Apple HIG、Material Design 的动态页面时遇到证书信任错误，未跳过 TLS 验证。其他可访问参考站已读取其公开页面。

每个云任务已隔离，后续开发使用当前检出即可。
